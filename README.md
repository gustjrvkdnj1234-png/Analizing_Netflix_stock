넷플릭스 주가 예측 데이터 분석 :
ARIMA 사용, 시계열 데이터 분석을 진행해보았으나,
주식 데이터 특성상 특정 범위를 예측한다는 점이 아쉬웠다.
또한 데이터 자체의 품질이 좋아, 여러 변수들에 의한 특성을 전처리하고, 가공하는 과정이 짧아 아쉬웠다.

이러한 점을 보완한다면, 현재 데이터를 수집해 미래를 예측하는데 있어
의사결정 지원에 근거를 마련할 수 있을 것이다라고 느꼈다.
